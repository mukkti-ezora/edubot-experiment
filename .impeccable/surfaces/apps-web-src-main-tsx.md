## Direction contract

Mode discipline: console surfaces = Operate; landing/login = Persuade-lite inside the same world. One visual world shared; Persuade tokens never distort console density.

THESIS: EduBot's console is an institutional control plane that earns trust through interaction precision, not decorative identity — the Cal.com grammar (ink monochrome, hairline-bounded white surfaces, near-black primary actions, tinted semantic status, keyboard-first command) applied to a multi-tenant education registry. It refuses both the current ledger-prototype look (hairline paper, serif chrome, empty space) and the generic SaaS-card dashboard.

OWN-WORLD: paper `#FAFAFA` ground, white surfaces, `--border` #E4E4E7-class hairlines, ink `#18181B` text, muted `#71717A`, near-black `#18181B` primary buttons hovering to `#27272A`; status communicated by quiet tinted chips (emerald/amber/rose/blue at 50–100 ground with 700 text, dot + label, never color alone); radius 6–8px stacked (6 controls, 8–10 cards/overlay); shadows with real offset reserved for overlays; Inter var with negative tracking on headings and tabular numerals on data; Source Serif 4 display only on landing; mono for codes/IDs/request IDs. Recognizable with content removed: a white table bound by one hairline, a dark button, a tinted status chip, a ⌘K affordance.

STORY: A Super Admin signs in through a composed split-screen gate, lands on a dashboard that answers "scale, health, attention, what's moving" in one scan, then operates lists with search + filter chips + polished dense tables, drills into institutional control centers, edits role capability matrices by domain, and reads audit as a forensic feed where every event answers who/what/where/when/result. They feel: this is real infrastructure.

FIRST VIEWPORT (console): left light sidebar 248px (wordmark + Platform mark, grouped nav with small-caps group labels, rounded active pill, collapse to icon rail), top bar 56px (mobile menu, breadcrumb, ⌘K command search, environment/scope marker "Platform", account menu with avatar). Content max 1200px, page head with title + context line + actions right. Dashboard below: 3-up metric strip, then institution-status landscape, attention rail, activity stream.

LANDING: sticky bordered nav, huge serif headline left + framed live-registry product panel right (real console vocabulary, synthetic labeled), then Available today vs Where EduBot is going as a typographic two-column split, proof without invented claims, footer sign-in path.

FORM: Cal.com operational grammar (user-pinned) as the base system — light surfaces, dark primary actions, menu/command-first interaction density, quiet chips — executed at full commitment; institutional identity carried by information hierarchy, indexing, and data discipline rather than ledger skeuomorphism. Seed: brief-pinned (no roll).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
