# Landing (Persuade)

Scope: public landing page, `/`. Visitor mode: Persuade.
Audience: institution leaders (principals, registrars, IT heads) evaluating EduBot first; returning students, teachers, parents and admins second.
Job: make EduBot intelligible and desirable in one viewport, prove it with the live product, send leaders to the live demo and returning users to sign in.
Proof: seeded demo data only, always labelled "Demo data". No invented customers, logos, testimonials or capabilities. No credentials printed on the page.
Constraints: PRODUCT.md banned list; no scroll-reveal fades; content visible by default without JavaScript timing.

## Direction contract

THESIS: The category standard for a modern school platform, played straight at Stripe's finish level. The live product is the hero, not a screenshot. Refuses the fake browser-chrome screenshot, invented testimonials and scroll-triggered fades.

OWN-WORLD: Cool neutral light ground (auto dark), one EduBot orange accent used only for primary action, live state and focus. Geist display set tight, Geist Mono only for data and IDs. 8px panels, 1px hairlines, a soft offset shadow only on the live console frame. Phosphor icons, one weight.

STORY: Leaders see the actual console running, understand it is one platform with four role portals, see tenancy, permissions and audit working, then open the live demo. Returning users find Sign in at once.

FIRST VIEWPORT: Left: two-line headline "One platform for every institution you run.", one sentence, "Explore the demo" primary and "Sign in" secondary. Right: the animated institution network, all 18 demo institutions orbiting the EduBot hub in status colours with audited events travelling to it (compact and centred under the copy below 1100px). Directly below, full width and bleeding past the fold: the live console frame rendered from real components with labelled demo data, its role switcher (Admin, Student, Teacher, Parent) re-composing the view in place.

FORM: Category standard (canon), chosen by the user over the roll; seed key 251a2096.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
